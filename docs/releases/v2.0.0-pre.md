# Maple Classic Auto Reporter v2.0.0-pre 發布說明

《新楓之谷：經典版 自動外掛檢舉工具》迎來重大架構升級！v2.0.0-pre 標誌著全新一代 PyWebView + React 18 現代化架構的就緒。

---

## 🚀 主要重大更新 (Major Highlights)

### 1. 全新現代化 Web 技術棧架構
- **PyWebView + React 18 + TypeScript + Vite**：告別過往笨重的傳統 GUI，採用現代化 Web 技術打造極致流暢、高質感暗色風格與微動效體驗的桌面介面。
- **Design Tokens & CSS 變數系統**：精準的層次結構、半透明磨砂玻璃質感、直覺的狀態指示與響應式互動元件。
- **強制 pnpm 套件管理**：前端全面改用 `pnpm` 進行快速、穩定的依賴管理與打包。

### 2. 極速辨識與不中斷遊戲體驗的檢舉流程
- **快速點選 OCR 候選與剪貼簿貼上**：錄影或截圖完成後，非同步辨識結果立即以標籤呈現，一鍵點選即可填入外掛 ID，並支援快速貼上已儲存名稱。
- **雙區域獨立辨識 (Dual Region OCR)**：自動分離遊戲左上角小地圖區塊與角色名稱區塊，精準自動填入所在地圖名稱，避免地圖字樣污染外掛 ID 欄位。
- **歷史資訊快捷資料帶入**：自動記憶與帶入歷史檢舉地圖與常用資料，省去重複輸入的繁瑣操作。
- **背景非同步送出檢舉**：按下送出後立即在背景排程上傳事證與 Playwright 自動化填表，不跳出遮擋、不搶焦點，完全不打斷玩家在遊戲內的戰鬥與操作體驗。

### 3. 查詢外掛是否被鎖功能 (官方懲處名單比對)
- **官方停權公告即時比對 (Sanctions Tracker)**：背景自動爬取並快取官方最新外掛停權懲處公告，在歷史紀錄中即時標註被檢舉對象是否已遭官方封鎖。

### 4. 多媒體擷取與音影同步
- **WASAPI Loopback 系統音效同步錄製**：背景擷取遊戲原聲，PyAV 原生封裝為標準 AAC + H.264 MP4 格式。
- **真實時間動態補幀技術**：解決錄影幀率抖動與倍速異常問題，確保產出影片總秒數與播放速度為精準 1:1 現實時間。
- **持續回放緩衝 (Replay Buffer)**：支援保留最近 10~60 秒畫面與音訊，隨時一鍵截取關鍵違規事證。

### 5. 系統級整合與安全機制
- **全域錄影快捷鍵**：Unity 遊戲視窗在前景時亦可直接透過全域快捷鍵觸發錄影或儲存回放。
- **Windows DPAPI 憑證防護**：Google OAuth Refresh Token 與 Discord Webhook URL 全面採用本機 DPAPI 加密儲存，絕不寫入明文檔案。
- **Playwright 自動化填表**：上傳事證後自動調用背景瀏覽器精確填寫遊戲橘子 SurveyCake 表單並驗證提交狀態。

## 📦 發行版本資訊

- **發行檔案**：`MapleClassicReporter-v2.0.0-pre-windows-x64.zip`
- **架構**：Windows x64 onedir 可攜式綠色資料夾（內建 Playwright Chromium、RapidOCR ONNX 模型與 WebView2 Runtime 整合）。
- **系統需求**：Windows 10 / Windows 11 (x64)
