# Maple Classic Auto Reporter v2.1.1 發布說明

## 主要更新

- 修正多版本差分鏈快取還原：確保早期版本（如 v2.0.0）更新至 v2.1.1 時能正確串接差分鏈並下載差分包，不會因快取遺落歷史版本節點而錯誤切換回下載 443 MB 完整包。
- 強化差分更新自動 Fallback：當差分包下載或校驗異常時，自動切換至完整包下載，避免更新流程中斷報錯。
- 修正更新下載期間重複觸發檢查更新的問題：下載進行中會自動禁用「檢查更新」按鈕與防護請求，避免下載狀態與線程衝突。
- 修正程式啟動時已存在快取更新資訊，但 Header 與設定頁未即時顯示新版本的問題。
- 啟動初始資料會同步帶入更新檢查狀態，確保「有可用更新」、下載進度與重新啟動提示正常顯示。
- 新增影片證據預覽右側的「於當前畫面進行辨識」按鈕。暫停影片後，可擷取目前播放位置的單張畫面，重新辨識角色 ID 與地圖名稱；截圖證據不會顯示此按鈕。
- 強化循環錄影 OCR：保留完整代表影格，支援 4K 回放，並延長高解析度影片的辨識時間，降低只在單一影格出現的角色名稱被漏掉的機率。
- 修正循環錄影沿用上一筆辨識角色名稱的問題。每次建立新證據時，會重新整理候選名稱與表單狀態。
- 修正取消辨識流程。按下取消後會停止 OCR 與進度更新，也可以再次儲存循環錄影片段。
- 檢舉表單內調整「背景靜默送出」後會立即儲存，下次檢舉會沿用最新設定。
- 改善角色名稱候選過濾，避免合法角色名稱被誤判為介面文字。

## 更新提醒

v2.1.0 使用者可以透過內建 updater 安裝差分包；若差分更新不可用，程式會改用完整 ZIP。較早版本使用者也可以直接下載完整 ZIP 更新。
