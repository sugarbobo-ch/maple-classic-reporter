# Maple Classic Reporter v1.1.0

這是相較於 `v1.0.0` 的功能與發行流程更新版。

## 主要更新

- 新增回放緩衝：持續保留最近一段遊戲畫面與系統聲音，發現違規時可直接保存片段。
- OCR 流程模組化：加入地圖目錄校正、影像前處理、候選排序、白名單過濾與背景辨識 worker，降低誤判與 UI 卡頓。
- 錄影與音訊流程強化：支援更穩定的即時補幀、WASAPI Loopback 系統聲音、PyAV H.264/AAC 合成，以及取消後的暫存清理。
- 上傳安全性提升：Google OAuth refresh token、Gemini API Key、Discord Webhook 使用 Windows DPAPI 保護；加入 HTTPS／目的地驗證與明確的上傳成功確認。
- 事證刪除更加保守：只有雲端上傳與官方表單都確認成功後，才會依使用者設定刪除本機事證。
- 歷史紀錄、雲端資料夾、事證網址與表單提交流程的錯誤訊息及可診斷資訊更加完整。

## 啟動與發行方式

- Windows 發行版從 one-file 改為 PyInstaller onedir bundle。
- Playwright Chromium、driver、RapidOCR 模型與應用程式資源放在同一個 `MapleClassicReporter/` 資料夾。
- 啟動時不再把整個大型 bundle 解壓到 `%TEMP%\_MEI...`，縮短啟動時間並降低暫存磁碟需求。
- 下載 ZIP 後必須完整解壓並保留資料夾結構，不能只搬移 `MapleClassicReporter.exe`。
