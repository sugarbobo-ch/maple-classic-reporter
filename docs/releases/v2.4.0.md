# Maple Classic Auto Reporter v2.4.0 發布說明

## 主要更新

- 新增多人批次檢舉：可一次建立角色名單，逐人保存檢舉紀錄，並為個別角色設定不同的違規說明。
- 同一批檢舉只上傳一次共用證據；自動模式會依序送出，手動模式會逐人提供官方表單欄位與確認流程。
- 新增批次進度與可恢復送件：送件中斷或結果不明時保留批次 ID 與每人的狀態，可確認已完成或允許重試，避免重複建立批次。
- 新增共用證據的安全清理邏輯：批次刪除紀錄時會同時考量本機檔案與 Google Drive 檔案的其他引用，並以批次方式更新歷史資料。
- 改善錄影、循環回放、設定、歷史紀錄與檢舉表單的狀態提示與操作流程。

## 修正與穩定性

- 修正手動檢舉助手可能顯示 `0 / 0` 人的進度問題。
- 修正角色 ID 輸入框直接失焦時未加入角色標籤的問題。
- 修正送件失敗重試時遺失批次 ID、造成後端重複建立批次的問題。
- 修正儲存草稿時覆蓋既有證據 URL 的問題。
- 修正共用證據清理的重複查詢與逐筆刪除，並補上批次送件、證據生命週期與表單互動回歸測試。

## 升級說明

可從 v2.3.0 使用應用程式內更新，或下載完整 ZIP 後解壓縮使用。升級不會刪除既有錄影、Google Drive 證據、歷史紀錄或使用者設定；共用證據清理仍需要使用者主動確認。
