# Maple Classic Auto Reporter v2.0.0 發布說明

## 主要更新

- 新增 Windows 可攜式 bundle 內建 updater，使用者可在程式內下載、驗證、重啟並套用更新。
- 新增 Header 更新狀態：可用更新、下載百分比、重啟應用、完成後重啟、空間不足與錯誤狀態。
- 新增穩定版與預覽版更新頻道，預設使用預覽頻道。
- 新增檔案級差分包、多版本差分鏈與完整 ZIP fallback。
- 新增 bundle manifest、update manifest、SHA-256 與 Ed25519 簽章驗證。
- 更新完成後自動清除下載包、暫存、rollback 備份與交易日誌。
- 使用者設定、OAuth token、Webhook、資料庫、歷史與錄影仍保存在 `%LOCALAPPDATA%\MapleClassicReporter\`。

## 發行檔案

- `MapleClassicReporter-v2.0.0-windows-x64.zip`
- 對上一個相容版本的檔案級差分包。
- `bundle-manifest-v1.json`
- `update-manifest-v1.json` 與簽章檔。
- `SHA256SUMS.txt`

## 導入提醒

v2.0.0 是第一個包含內建 updater 的正式版。v2.0.0-pre 或更早版本的使用者需要最後一次手動下載完整 ZIP；完成導入後，後續版本可直接由程式更新。
