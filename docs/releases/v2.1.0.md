# Maple Classic Auto Reporter v2.1.0 發布說明

## 主要更新

- 新增影片證據預覽右側的「於當前畫面進行辨識」按鈕。暫停影片後，可擷取目前播放位置的單張畫面，重新辨識角色 ID 與地圖名稱；截圖證據不會顯示此按鈕。
- 強化循環錄影 OCR：保留完整代表影格，支援 4K 回放，並延長高解析度影片的辨識時間，降低只在單一影格出現的角色名稱被漏掉的機率。
- 修正循環錄影沿用上一筆辨識角色名稱的問題。每次建立新證據時，會重新整理候選名稱與表單狀態。
- 修正取消辨識流程。按下取消後會停止 OCR 與進度更新，也可以再次儲存循環錄影片段。
- 檢舉表單內調整「背景靜默送出」後會立即儲存，下次檢舉會沿用最新設定。
- 改善角色名稱候選過濾，避免合法角色名稱被誤判為介面文字。
